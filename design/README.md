# design/ — références visuelles

> Dossier de **référence**, hors du code de l'application. Le design system réel vit dans `apps/web/src/styles/globals.css` (créé à l'étape E10, à partir de `design/globals.css`).

| Fichier | Rôle |
|---|---|
| `globals.css` | Source du design system (couleurs OKLCH, typographie, rayons, ombres, tokens de carte) |
| `prompt-claude-design.md` | Prompt de départ de la maquette Explorer |
| `prompts-ecrans.md` | Prompts des écrans complémentaires (fiche lieu, calendrier, hors région, Sources, erreurs…) |
| `maquettes/` | Captures des maquettes validées (mobile 390 px et desktop 1440 px) |
